# QUẢN LÝ PHÒNG KHÁM LONG CHÂU

## 1. Giới thiệu

Đồ án xây dựng hệ thống quản lý phòng khám nhằm hỗ trợ quản lý các hoạt động cơ bản của phòng khám, bao gồm quản lý bệnh nhân, bác sĩ, lịch hẹn, khám bệnh, bệnh án, thuốc, đơn thuốc, hóa đơn và thanh toán.

## 2. Công nghệ sử dụng

- Java
- MySQL
- Git
- GitHub

## 3. Đối tượng sử dụng

- Quản trị viên
- Lễ tân
- Bác sĩ
- Nhân viên thu ngân

## 4. Chức năng chính

- Đăng nhập và phân quyền
- Quản lý bệnh nhân
- Quản lý bác sĩ
- Quản lý lịch hẹn
- Tiếp nhận bệnh nhân
- Khám bệnh
- Quản lý bệnh án
- Quản lý thuốc
- Kê đơn thuốc
- Lập hóa đơn
- Thanh toán
- Thống kê

## 5. Quy trình chính

Tiếp nhận bệnh nhân → Đặt lịch → Khám bệnh → Kê đơn → Thanh toán → Thống kê

## 6. Tiến độ thực hiện

- Tuần 1: Khởi động và khảo sát
- Tuần 2: Phân tích yêu cầu
- Tuần 3: Phân tích hệ thống và UML
- Tuần 4–5: Thiết kế và xây dựng cơ sở dữ liệu
- Tuần 6–12: Phát triển hệ thống
- Tuần 13: Kiểm thử
- Tuần 14: Hoàn thiện
- Tuần 15: Đóng gói và bảo vệ
